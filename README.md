# ДСК · AI-помощник продаж недвижимости

Комплексная цифровая платформа для девелопера и клиентов с каталогом объектов, интерактивным ходом строительства, CRM-модулем ведения сделок, согласованием коммерческих предложений и интеллектуальным AI-ассистентом менеджера продаж на базе GigaChat и RabbitMQ.

---

## 🏛 Состав системы и сервисов

Платформа состоит из независимых микросервисов, разворачиваемых в едином контуре:

| Сервис | Стек | Порт / URL | Назначение |
|---|---|---|---|
| **Frontend** | React 18, TypeScript, Tailwind CSS, Vite, Nginx | `http://localhost:5173` | Веб-интерфейс для покупателей, менеджеров продаж и руководителей (SPA). |
| **User Server** | Go 1.23, Chi, pgx, JWT | `http://localhost:8080` | Клиентский REST API: авторизация, каталог ЖК и квартир, ход стройки, чаты, просмотр сделок и КП. |
| **Staff Server** | Go 1.23, Chi, pgx, JWT | `http://localhost:8081` | Корпоративный REST API: CRM сделок, чаты, согласование скидок, объекты, конкуренты, ERP и вызовы AI. |
| **Agent Service** | Python 3.12, FastAPI, LangGraph, GigaChat API, aio-pika | `http://localhost:8000` | Сервис AI-агентов (аналитика, переговоры, контраргументы, формирование КП, анализ диалогов). |
| **Database** | PostgreSQL 15 | `localhost:5432` | Реляционное хранилище данных, миграций и снимков состояния. |
| **Message Broker** | RabbitMQ 3 Management | `localhost:5672`<br>`http://localhost:15672` | Шина событий и двусторонний асинхронный RPC-обмен между Backend и AI-агентом. |

## 🚀 Быстрый запуск

### 1. Запуск всего проекта через Docker Compose

Для запуска с реальными ответами нейросети скопируйте `.env.example` в `.env` и укажите ваш ключ `GIGACHAT_CREDENTIALS`:

```bash
docker compose up --build
```

### 2. Доступ к сервисам после запуска

- **Веб-приложение (Frontend)**: <http://localhost:5173>
- **Документация User API (Swagger UI)**: <http://localhost:8080/swagger/>
- **Документация Staff API (Swagger UI)**: <http://localhost:8081/swagger/>
- **Healthcheck AI-агента**: <http://localhost:8000/health>
- **RabbitMQ Management UI**: <http://localhost:15672> (логин: `guest`, пароль: `guest`)

### 3. Демонстрационные данные

При первом запуске база данных автоматически инициализирует схему и каталог объектов. Для повторной накатки или обновления демо-данных выполните:

```bash
sh backend/scripts/seed-demo.sh
```

## 💡 Функциональные возможности платформы

### 1. Каталог недвижимости и ход строительства
- Иерархическая структура: Жилые комплексы → Дома/Корпуса → Квартиры, парковочные места и кладовые.
- Параметры объектов: комнатность, этаж, площадь, тип отделки (`rough`, `white_box`, `turnkey`), статус (`free`, `booked`, `sold`), планировки и цены.
- Мониторинг динамики строительства: этапы работ (земляные работы, фундамент, каркас, кровля, отделка), процент готовности, статус задержек и уровень риска (`low`, `medium`, `high`).
- Синхронизация с ERP: фиксация задержек поставок материалов, производственных графиков и изменений сроков сдачи.

### 2. Управление сделками и коммерческими предложениями (КП)
- Расчёт коммерческих предложений с учётом действующих политик скидок по корпусам и ролям сотрудников.
- Двухуровневый лимит скидок:
  - **Менеджер** — базовая скидка (до 5%).
  - **Руководитель** — повышенная скидка (до 15%).
- Автоматический workflow согласования: если скидка превышает лимит менеджера, КП направляется супервайзеру с возможностью одобрения или отклонения с указанием причины.
- Генерация PDF-документов коммерческих предложений и отправка клиенту на email по SMTP.

### 3. Интеллектуальный AI-ассистент (GigaChat + LangGraph)
AI-сервис интегрирован через шину RabbitMQ (`app.topic`) и выполняет роли:
- **Router Agent** — автоматическая классификация запроса менеджера по намерениям (аналитика, переговоры, КП, общий вопрос).
- **Analytics Agent** — оценка рисков задержки сдачи объекта, сравнение плановых и прогнозных дат, извлечение предпочтений клиента из истории переписки.
- **Negotiation Agent** — подготовка фактологических контраргументов против конкурентов по району (цена за м², отделка, сроки, инфраструктура) без галлюцинаций.
- **Offer Agent** — помощь в подборе альтернативных квартир и параметров сделки при отказе клиента.
- **Dialog Analysis & Reply Assist** — анализ переписки в чате, выделение ключевых фактов о клиенте и генерация черновика ответа для менеджера.
- **Domain Event Handlers** — реакция на события стройки (автоматический расчёт влияния задержек на сделки) и изменение статуса КП.

## 🛠 Локальная разработка без Docker

### 1. Запуск Backend (Go)
Требуются запущенные PostgreSQL и RabbitMQ.

```bash
cd backend
go run ./cmd/user_server/main.go   # Запуск User Server на :8080
go run ./cmd/staff_server/main.go  # Запуск Staff Server на :8081
```

### 2. Запуск AI-агента (Python)
```bash
cd agent
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Запуск Frontend (Vite)
```bash
cd frontend
npm install
npm run dev
```
Интерфейс будет доступен по адресу `http://localhost:5173`.
